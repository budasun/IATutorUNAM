# IA Tutor UNAM

Tutor inteligente desarrollado con Next.js y TypeScript, orientado a apoyar procesos de aprendizaje.

## 🚀 Demo en vivo
[https://ia-tutor-unam.vercel.app](https://ia-tutor-unam.vercel.app)

## ✨ Características
- Interfaz moderna construida con Next.js
- Tipado completo con TypeScript
- Arquitectura escalable y componentes reutilizables
- Optimizado para rendimiento y SEO

## 🛠️ Tech Stack
- **Framework:** Next.js
- **Lenguaje:** TypeScript
- **Estilos:** CSS / Tailwind
- **Deploy:** Vercel
